# TypeScript Vehicle Project 🚗

A simple TypeScript project demonstrating **Object-Oriented Programming (OOP)** concepts using **interfaces and classes**, compiled to JavaScript and executed with Node.js.

This project is ideal for:
- Learning TypeScript fundamentals
- Understanding interfaces vs classes
- Practicing a real-world TypeScript build workflow
- DevOps/CI pipeline demonstrations

---

## 📌 Features

- TypeScript interface (`Vehicle`)
- Class implementation (`Car`)
- Constructor usage
- Method overriding
- TypeScript compilation (`tsc`)
- Clean project structure (`src → dist`)
- Ready for CI/CD and Dockerization
